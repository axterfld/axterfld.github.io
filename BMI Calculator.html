什么是 BMI？

BMI（Body Mass Index，身体质量指数）是用身高和体重估算胖瘦程度的常用指标， 计算公式为 BMI = 体重(kg) ÷ 身高(m)²。 它简单、直观，常被用于快速筛查体重是否处在健康区间。

关于这个计算器

这是一个纯前端实现的 BMI 计算器，所有运算都在你的浏览器本地完成， 不会上传也不会保存任何数据。界面提供白天 / 黑夜两套配色， 点击右上角的开关即可切换。

使用方法

  1. 在“身高”栏输入以米为单位的身高，例如 1.70。
  2. 在“体重”栏输入以千克为单位的身重，例如 65。
  3. 点击“开始计算”（或在输入框内按回车键）。
  4. 上方结果区会显示 BMI 数值与对应的体重等级。

结果参考范围

  • 过轻：BMI < 18.5
  • 正常：18.5 ≤ BMI < 25
  • 过重：25 ≤ BMI < 28
  • 肥胖：28 ≤ BMI < 32
  • 严重肥胖：BMI ≥ 32

BMI 仅为参考指标，不能替代专业医疗建议。
